# Compose Lists & Navigation

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat-square&logo=kotlin&logoColor=white)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-4285F4?style=flat-square&logo=jetpackcompose&logoColor=white)

A list → details app in Jetpack Compose: a `LazyColumn` list, **Navigation Compose** with arguments passed to the details screen, Material 3 app bars and light/dark theming.

> Lab #2 · Mobile Application Development course. Ukrainian version: [README.uk.md](README.uk.md)

## Features

- Efficient lists with `LazyColumn`
- Navigation between list and details with an item argument
- `TopAppBar` / `CenterAlignedTopAppBar` inside `Scaffold`
- Material 3 theme that follows the system dark mode

## Tech stack

Kotlin · Jetpack Compose · Navigation Compose · Material 3

## Run locally

Open in Android Studio, let Gradle sync, run on API 26+.
